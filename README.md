# Python Auth CLI 🔐

Sistema de autenticação desenvolvido em Python para execução via linha de comando.

## Funcionalidades

- Cadastro de usuários
- Login
- Hash seguro de senhas com Argon2
- Validação de dados
- Persistência com SQLite
- Testes automatizados com Pytest
- Lint e análise de código com Ruff

## Tecnologias

- Python
- SQLite
- Argon2
- Pytest
- Ruff
- Poetry
- Git

## Como executar

```bash
poetry install
poetry run python main.py
```
## Projeto desenvolvido para praticar conceitos de autenticação, segurança, persistência de dados e testes em Python.
